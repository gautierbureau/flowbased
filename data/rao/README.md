# OpenRAO example resources

Source: powsybl/pypowsybl, tag `v1.15.0`, directory `data/rao/` (MPL-2.0).
See `../../NOTICE.md`. Re-download with `bash ../../scripts/fetch_rao_data.sh`.

- `rao_network.uct`     — 12-node UCTE network (4 countries, 1 PST)
- `rao_crac.json`       — CNECs, one contingency, one preventive PST range action
- `rao_parameters.json` — RAO parameters (RaoParameters format v3.3)
- `rao_glsk.xml`        — GLSK, required because loop-flow computation is enabled
